# Word lists

`english_words.txt.gz`: ordinary English words, lowercase, one per line (the
American and British lists of SCOWL, as packaged by Debian in `wamerican` and
`wbritish`, proper nouns left out). The blind CV's mask repair uses it to tell
a word an employer's name happens to be part of ("Digital", at Digi) from a
brand ("MyDigi"), which stays masked.
